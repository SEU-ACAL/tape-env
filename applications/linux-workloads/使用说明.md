# Linux 工作负载

`applications/linux-workloads/firemarshal/` 是仓库自有的精简 FireMarshal 层，保留了
Buildroot 工作负载构建、无磁盘启动组装和 Spike 启动支持。Buildroot 是唯一的直接子模块；
Linux、OpenSBI 和 BusyBox 均由工作负载 defconfig 下载并固定版本。

克隆后初始化 Buildroot：

```sh
./init-submodules.sh --linux
```

## P2E

P2E 平台没有 Linux 块设备，因此默认工作负载采用无磁盘模式：Buildroot 根文件系统作为
initramfs 嵌入启动 ELF，并需要预加载到 DDR。

使用专用 FireMarshal 开发环境构建默认工作负载。该环境不包含默认 shell 所需的仿真器和 RTL
工具链：

```sh
nix develop .#firemarshal --command applications/scripts/build-linux-workload.sh
```

生成的 P2E ELF 位于：

```text
applications/linux-workloads/build/tape-env/tape-env-linux-poweroff/
  tape-env-linux-poweroff-bin-nodisk
```

自定义 P2E 工作负载的移植、向根文件系统打包文件以及通过 P2E 运行 ELF 的方法见
[WORKLOADS.zh-CN.md](WORKLOADS.zh-CN.md)；可使用 `--verify-spike` 在 Spike 中运行已完成的
非 HTIF 无磁盘工作负载。

## HTIF 控制台

P2E 平台不会将物理 UART TX 转发到主机。HTIF 控制台工作负载通过 OpenSBI 和 HTIF 输出
Linux 日志：

```sh
nix develop .#firemarshal --command applications/scripts/build-linux-workload.sh --htif-console
```

该命令还会生成 DTB。运行时应同时预加载 ELF 和 DTB：

```sh
cd dependencies/p2e-runner
p2e run \
  --image ../../applications/linux-workloads/build/tape-env/tape-env-linux-htif-console/tape-env-linux-htif-console-bin-nodisk \
  --dtb ../../applications/linux-workloads/build/tape-env/tape-env-linux-htif-console/tape-env-linux-htif-console.dtb \
  --dtb-address 0x8ff00000
```

不要同时使用 `--htif-console` 与 `--verify-spike`：P2E OpenSBI payload 要求 DTB 位于
`0x8ff00000`，而 Spike 使用自己的 ROM 约定。

无磁盘流程仍使用 `guestmount` 将 ext2 根文件系统转换为 initramfs。执行构建前，需要在主机
安装 `libguestfs`。构建产物不纳入 Git 管理。
