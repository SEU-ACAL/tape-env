# Linux RISC-V Benchmark 示例

这是一个完整的 Linux 工作负载示例。它移植 CI 所使用的 benchmark 子集，且不修改
`applications/riscv-tests`：上游源码会复制到临时目录，仅替换其裸机运行时。

在仓库根目录构建 guest payload：

```sh
nix develop .#firemarshal --command \
  applications/linux-workloads/examples/riscv-benchmarks/build.sh
```

该命令会向 `build/` 写入 11 个静态 RISC-V Linux 可执行文件和一个套件运行器。
`applications/linux-workloads/workloads/riscv-benchmarks.json` 将该目录复制到
`/opt/riscv-benchmarks`，并作为通过 P2E 打包和运行此示例的 FireMarshal 配置。

`pmp` benchmark 被明确标记为跳过，因为它需要机器模式的 PMP CSR 访问，而 Linux 用户进程
无法获得该权限。
